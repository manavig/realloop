# RealLoop

Marketing site for RealLoop — AI Quality Assurance.

## Files
- `index.html` — the live site (dark variant, most built-out)
- `variant-light.html` — earlier light-theme version
- `variant-dark.html` — earlier dark-theme version

## Editing
It's a single self-contained HTML file (the only external dependency is Google Fonts).
To edit in the browser: open `index.html` on GitHub → click the pencil icon → make changes → **Commit changes**.
To edit locally: clone the repo, open `index.html` in any browser to preview, edit, then commit and push.
